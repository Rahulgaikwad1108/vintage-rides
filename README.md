# Vintage Rides 🏍️✨

A nostalgic, interactive retro Indian motorcycle garage experience built with React and Vite.

## Tech Stack

* **Frontend**: React 18, Vite, JavaScript, CSS3, HTML5
* **Icons**: Lucide React
* **Audio Integration**: YouTube IFrame Player API

## Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
